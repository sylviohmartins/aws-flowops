# Project sanitation

Establish a baseline, classify candidates as proven dead / likely dead / ambiguous, and remove only high-confidence dead material. Preserve botocore discovery, dynamic configuration and externally referenced assets unless absence of use is proven. Keep cleanup behavior-neutral and re-run the baseline after changes.
