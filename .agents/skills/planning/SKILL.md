# Planning

Discover the relevant implementation before proposing a solution.

- State observable objective rather than implementation guesses.
- Define acceptance criteria and non-goals.
- Identify affected FlowOps invariants and AWS/persistence/security/compatibility/deployment impact.
- Choose tests/checks before implementation.
- Use parallel work only when dependencies and file ownership are provably disjoint.
- Do not over-plan a clear low-risk change.
