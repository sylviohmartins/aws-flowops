# Documentation

Prefer canonical documentation and links over duplicated policy. Update docs when public behavior, operational procedures, security assumptions, compatibility or deployment changes. Use ADRs for durable architectural decisions. Keep examples safe and non-secret. Verify commands against repository configuration before publishing them.
