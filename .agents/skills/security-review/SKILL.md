# Security review

Read security, AWS-safety and agent-supply-chain rules. Inspect changed trust boundaries, secrets/logging, account/region/resource validation, production controls, approval paths, generic Action allowlisting, dependencies and GitHub workflow permissions. Prefer concrete exploitable paths over generic security commentary. Never request or print real credentials.
